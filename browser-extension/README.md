# Huobao Drama Browser Helper

화보 드라마 작업대에서 만든 프롬프트를 Google Flow 또는 Suno 같은 구독형 웹 생성 서비스 입력창으로 전달하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 폴더 `browser-extension`을 선택합니다.

## 사용

1. 앱을 `http://localhost:3013`에서 엽니다.
2. 회차 작업대에서 이미지, 영상, BGM 등의 `프롬프트/등록` 창을 엽니다.
3. `Flow로 보내기` 또는 `Suno로 보내기` 버튼을 누릅니다.
4. 확장 프로그램이 대상 탭을 열고 프롬프트 입력창에 내용을 넣습니다.
5. 화면 오른쪽 아래 자동화 패널에서 생성 버튼 후보를 확인합니다.
6. 서비스 화면에서 로그인 상태, 정책 안내, 생성 옵션을 확인한 뒤 `생성 버튼 클릭`을 누릅니다.
7. 완료 후 `버튼 다시 찾기`로 다운로드 버튼 후보를 찾고, 필요하면 `다운로드 클릭`을 누릅니다.
8. 완성 파일을 앱의 결과 등록 창에 연결합니다.

## 범위

- 이 확장 프로그램은 프롬프트 입력, 생성 버튼 후보 탐지, 사용자 승인 후 클릭, 다운로드 버튼 후보 탐지를 보조합니다.
- 최종 생성/다운로드 클릭은 사용자가 자동화 패널에서 승인해야 실행됩니다.
- 웹 서비스 UI가 바뀌거나 로그인이 풀리면 입력창 탐지가 실패할 수 있습니다.
