# Huobao Drama Browser Helper

화보 드라마 작업대에서 만든 프롬프트를 Google Flow 또는 Suno 같은 구독형 웹 생성 서비스 입력창으로 전달하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 폴더 `browser-extension`을 선택합니다.

## 사용

1. 앱을 `http://localhost:3013`에서 엽니다.
2. Flow 또는 Suno에 먼저 로그인합니다.
3. Flow는 생성 프로젝트 또는 프롬프트 입력 화면까지 직접 열어 둡니다.
4. 회차 작업대에서 이미지, 영상, BGM 등의 `프롬프트/등록` 창을 엽니다.
5. `Flow로 보내기` 또는 `Suno로 보내기` 버튼을 누릅니다.
6. 확장 프로그램이 이미 열린 로그인 탭을 우선 재사용하고, 없으면 대상 탭을 새로 엽니다.
7. 화면 오른쪽 아래 자동화 패널에서 입력 후보와 생성 버튼 후보를 확인합니다.
8. 서비스 화면에서 로그인 상태, 정책 안내, 생성 옵션을 확인한 뒤 `생성 버튼 클릭`을 누릅니다.
9. 완료 후 `버튼 다시 찾기`로 다운로드 버튼 후보를 찾고, 필요하면 `다운로드 클릭`을 누릅니다.
10. 완성 파일을 앱의 결과 등록 창에 연결합니다.

## Flow 사용 팁

- Flow는 첫 화면, 프로젝트 선택 화면, 정책 확인 화면에서는 프롬프트 입력창이 없을 수 있습니다.
- 그럴 때는 자동화 패널에 `새 프로젝트 클릭` 또는 `Flow 팝업 진행` 버튼이 표시될 수 있습니다.
- `새 프로젝트 클릭`은 Flow 화면의 `새 프로젝트` 버튼을 찾았을 때만 표시됩니다.
- `Flow API 프로젝트 생성`은 Flow 로그인 토큰이 캡처된 경우 버튼 클릭 대신 Flow 프로젝트 생성 API를 직접 호출합니다.
- 해당 버튼이 보이지 않으면 Flow 탭에서 입력 화면까지 직접 이동한 뒤 앱에서 `Flow로 보내기`를 다시 누르세요.
- 자동화 패널의 `프롬프트 다시 입력` 버튼은 현재 열린 화면에서 입력창을 다시 탐색합니다.
- 패널에는 현재 화면의 입력 후보 수와 버튼 후보 수가 표시됩니다. 입력 후보가 0개면 아직 입력 화면이 아닐 가능성이 큽니다.

## Flow API 브리지

- 이 확장 프로그램은 Flow가 `aisandbox-pa.googleapis.com` 또는 `labs.google`로 보내는 요청의 `Bearer ya29...` 로그인 토큰 존재 여부를 로컬에서 감지합니다.
- 토큰 원문은 앱 백엔드로 보내지 않고, 토큰이 있는지와 캡처 시각만 `http://127.0.0.1:5679` 로컬 백엔드에 알립니다.
- 권한이 추가되었으므로 업데이트 후 `chrome://extensions`에서 확장을 다시 로드해야 합니다.
- 토큰이 캡처되지 않으면 Flow 탭을 열어 로그인한 뒤 Flow 화면에서 한 번 새로고침하거나 일반 조작을 한 다음 다시 시도하세요.

## 범위

- 이 확장 프로그램은 프롬프트 입력, 생성 버튼 후보 탐지, 사용자 승인 후 클릭, 다운로드 버튼 후보 탐지를 보조합니다.
- 최종 생성/다운로드 클릭은 사용자가 자동화 패널에서 승인해야 실행됩니다.
- 웹 서비스 UI가 바뀌거나 로그인이 풀리면 입력창 탐지가 실패할 수 있습니다.
